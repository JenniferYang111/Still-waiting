# Still-waiting

Still Waiting is a short quiz about what you do when an answer takes time. It runs in your browser using HTML, CSS, and JavaScript.

## Open the prototype

Clone this repository or download and extract its ZIP from GitHub. Keep `index.html`, `styles.css`, and `script.js` in the same folder, then open `index.html` in a browser.

## How to play

1. Select one of the four choices to submit your answer. The result appears 15 seconds later, with no countdown.
2. While you wait, press and hold **Speed Up** or the **Spacebar** to add bubbles and deepen the red background. A quick tap has no effect. Release it to pause the buildup. Hold it again to resume from where you left off.
3. After about four seconds of total hold time, the bubbles fill the screen and burst. The **Speed Up** control disappears, and the screen stays black for the rest of the wait.
4. When the result appears, read the explanation and see how many holds you used. Select **Next Question** to try another puzzle.
