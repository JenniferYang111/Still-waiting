# Still-waiting

Still Waiting is a short quiz about what you do when an answer takes time. It runs in your browser using HTML, CSS, and JavaScript.

## Open the prototype

Clone this repository or download and extract its ZIP from GitHub. Keep `index.html`, `styles.css`, and `script.js` in the same folder, then open `index.html` in a browser.

## How to play

1. Select one of the four choices to submit your answer. The result appears 15 seconds later, with no countdown.
2. While you wait, you can press **Speed Up**. The first press tints the background red and adds a few bubbles. Each further press deepens the tint and adds bubbles. Pressing the button leaves the reveal time unchanged.
3. On the seventh press, the bubbles fill the screen. The eighth press triggers the burst and removes the button. After the burst, the screen stays black for the rest of the wait.
4. When the result appears, read the explanation and see how many times you pressed **Speed Up**. Select **Next Question** to try another puzzle.
